# Brand assets

Copied unchanged from the `branding/export/` folder of the main Kantahe brand repo (commit 65d7e6b
of that repo, rebuilt there with `python3 branding/build.py`). Do not edit these files here:
change the brand in that repo and copy the new exports. To check that the copies still match, run
`KANTAHE_BRAND_EXPORT=<that export folder> flutter test test/branding_test.dart`.

- `icon-1024.png`, `icon-512.png`, `icon-256.png`, `icon-128.png`: the app icon (macOS and Windows icons are made from icon-1024).
- `lockup-dark.png` and `lockup-light.png`: the icon with the "kantahe" wordmark, for dark and for light backgrounds.
- `mark-512.png`: the icon on its own.
